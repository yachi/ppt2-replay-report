全個表面幾乎唔會重複，所以查表唔睇成個 board，淨係睇方塊落腳附近：方塊嘅形狀，加埋佢左右各一行同佢落腳位嘅高低差（差 3 格以上當 3 格）。左右鏡像當同一個情況（J 同 L、S 同 Z 對調）。每個落位計「高手見到呢個情況幾多次、揀咗幾多次」，揀率會向平均值拉近少少，免得得一兩次嘅情況排太前。

兩粒組合：第一粒每個可行位置擺落去（會清行就清行），再喺新 board 上面計第二粒，兩粒嘅揀率相乘排序。打和就用 El-Tetris 評分（高度、清行、窿、凹凸）決定。
